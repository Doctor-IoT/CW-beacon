# CWbeaconWeb

**IoT-controlled HF CW (Morse code) beacon — NodeMCU v2 / ESP8266**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

An amateur radio CW beacon for the 14 MHz (20 m) band, based on the NodeMCU v2 (ESP8266) and a Si5351A clock synthesizer IC. The beacon transmits an authenticated Morse code message and can be fully controlled remotely via a Telegram bot, a built-in web interface, or a serial console — no RF hardware access required.

Originally built for the **130th anniversary of Marconi's first radio transmission**, deployed at Concordia Station, Antarctica.

> Project blog: <https://doctoriot.wordpress.com/beacon-cw-14-mhz-3w/>

---

## Features

- **RF carrier** generated by the Si5351A over I²C; CLK0 output keyed in sync with the Morse timing
- **Non-blocking Morse** sender — uses `millis()` internally so the main loop stays responsive
- **Authenticated transmissions** — each message carries a 4-hex Fletcher-16 CRC computed over the current UTC timestamp and a fixed salt, allowing independent verification by any receiver that knows the salt
- **Wi-Fi** — STA mode with automatic fallback to AP mode (`CWbeacon-AP`) if no network is reachable
- **Web interface** — status page + full configuration form at `http://<device-ip>/`
- **OTA firmware update** at `http://<device-ip>/update` (password-protected)
- **Telegram bot** — 15 commands for real-time control and status
- **NTP time sync** from `pool.ntp.org`, UTC, resync every hour
- **Serial console** at 115200 baud — diagnostics and credential recovery
- **EEPROM-backed config** — all settings survive power cycles

## Required Libraries

Install via **Arduino IDE → Library Manager**:

| Library | Purpose |
|---|---|
| [AsyncTelegram2](https://github.com/cotestatnt/async-telegram-bot) | Telegram Bot API over BearSSL/TLS |
| [ArduinoJson](https://arduinojson.org/) | JSON parsing (used by AsyncTelegram2) |
| [NTPClient](https://github.com/arduino-libraries/NTPClient) | Network Time Protocol client |
| [UnixTime](https://github.com/GyverLibs/UnixTime) | Unix timestamp → calendar field decomposition |
| ESP8266 Arduino core | `ESP8266WiFi`, `ESP8266WebServer`, `ESP8266HTTPUpdateServer`, … |

The **Si5351** driver (`si5351.cpp` / `si5351.h`) is included in this repository as a local copy of the [Etherkit Si5351 library](https://github.com/etherkit/Si5351Arduino), with no modifications.

The **Morse sender** (`morse.cpp` / `morse.h`) is a modified version of the [MorseSender](https://github.com/markfickett/arduinomorse) library. The key change is in `LEDMorseSender::setOn()` and `setOff()`: in addition to driving the LED GPIO, they call `beacon.output_enable(SI5351_CLK0, 1/0)` over I²C to gate the RF carrier in perfect sync with the Morse timing.

## Configuration

All parameters are stored in the ESP8266's emulated EEPROM (SPI flash, 512 bytes) and can be set via the web interface, the Telegram bot, or the serial console.

### First-time setup

1. Flash the firmware.
2. On first boot the device starts in **AP mode** (SSID: `CWbeacon-AP`, same password).
3. Connect to the AP and open `http://192.168.4.1/` in a browser.
4. Enter your Wi-Fi credentials, Telegram bot token, authorized user IDs, beacon call sign, carrier frequency (Hz), and QTC message.
5. Click **Apply Settings**, then **Restart**.

### Key parameters

| Parameter | Default | Description |
|---|---|---|
| Call sign (`qrz`) | `ia/iu0szs` | Station call sign — **must be lowercase** for the Morse library |
| QTC message (`message`) | `130yr pb14qv` | Free-text payload (max 32 chars) |
| Carrier frequency (`qrg`) | `14096950` Hz | In Hz as a text string; stored in EEPROM |
| Calibration factor (`fcal`) | `100` | Signed Hz offset to compensate Si5351A crystal error |
| Morse speed (`wpm`) | `12` | Words per minute (PARIS timing) |
| TX gap (`TXPAUSE`) | `15` s | Gap between consecutive transmissions (edit in source) |
| Admin password | `12345678` | Protects the web setup page and OTA endpoint |

### CRC authentication

Each transmitted message ends with a 4-character hex CRC:

```
ia/iu0szs 130yr pb14qv a3c2
                        ^^^^-- Fletcher-16 CRC
```

The CRC is computed over `"yymmddhhmm" + "25041874"` (current UTC time in minute resolution + Marconi's birthday as salt). Any receiving station that knows the salt can independently verify the timestamp and authenticity of each transmission.

> **Security note:** the salt `"25041874"` is publicly documented here. For a stronger scheme, change it to a private value via the source code and do not publish it.

## Telegram Bot Commands

| Command | Description |
|---|---|
| `/help` | List all available commands |
| `/stat` | Full status: message, QRG, speed, beacon state, RSSI, IP, uptime |
| `/beaconon` | Enable the RF transmitter |
| `/beaconoff` | Disable the RF transmitter |
| `/getqrg` | Report the current carrier frequency |
| `/getcal` | Report the current calibration factor |
| `/getmsg` | Report the current QTC payload |
| `/getqrz` | Report the current call sign |
| `/getspd` | Report the current Morse speed (WPM) |
| `/info` | Report the firmware revision string |
| `/reboot` | Gracefully reboot the device |
| `/setqrg N` | Set carrier frequency to N Hz (saves to EEPROM) |
| `/setcal N` | Set calibration factor to N (saves to EEPROM) |
| `/setmsg T` | Set QTC text to T (max 32 chars, saves to EEPROM) |
| `/setqrz C` | Set call sign to C (max 16 chars, saves to EEPROM) |
| `/setspd W` | Set Morse speed to W WPM (1–30, saves to EEPROM) |

Only user IDs listed in the EEPROM configuration are allowed to send commands. Unauthorized senders are silently dropped and the admin user is notified.

## Serial Console Commands

Connect at **115200 baud, 8N1**. Type the first three characters of the command and press Enter.

| Command | Description |
|---|---|
| `adm` | Toggle admin mode (echoes debug data on web form submissions) |
| `hel` | Print all available commands |
| `inf` | Print firmware version, Wi-Fi info, and chip diagnostics |
| `pwdres` | Reset admin password to `12345678` and reboot |
| `res` | Restart immediately |
| `seta<P>` | Set admin password to P in RAM (not persisted to EEPROM) |
| `setn<N>` | Set and persist the system name to N |
| `setp<P>` | Set and persist the Wi-Fi password to P |
| `sets<S>` | Set and persist the Wi-Fi SSID to S |
| `set?` | Print current system name, SSID, and password |
